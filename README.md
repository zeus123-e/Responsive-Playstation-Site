# Playstation Store - Página de Produto

Este é um projeto de uma página informativa para um controle do PlayStation 4, com foco em mostrar detalhes sobre o produto. A página é responsiva e foi desenvolvida utilizando **HTML**, **CSS** e **JavaScript**. O design foi pensado para proporcionar uma boa experiência tanto em dispositivos móveis quanto em desktops.

## Funcionalidades

- **Layout Responsivo**: O site se adapta automaticamente a diferentes tamanhos de tela, garantindo que a visualização seja adequada tanto em dispositivos móveis quanto em desktops.
- **Menu de Navegação**: O menu de navegação se ajusta para exibir um menu hamburguer em telas menores, oferecendo uma navegação simples e intuitiva.
- **Informações do Produto**: Detalhes sobre o produto, como nome, descrição, preço e características, são exibidos de maneira clara e objetiva.
- **Ícones de Redes Sociais**: Ícones de redes sociais (Facebook, Twitter e Instagram) ficam fixos na parte inferior da página, permitindo fácil compartilhamento do conteúdo.
- **Imagens do Produto**: Exibição de imagens do controle para uma visualização completa do produto.

## Tecnologias Utilizadas

- **HTML**: Estruturação básica do conteúdo da página.
- **CSS**: Estilização do layout e design responsivo.
- **JavaScript**: Interatividade, como o menu interativo e controle de visibilidade dos itens.
